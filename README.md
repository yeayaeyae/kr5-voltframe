# КР №5 — VOLTFRAME SPA на React

**Студент:** Кигози Елисей Маликовчи · **Группа:** ЭФБО-13-25

SPA магазина электроники, продолжающий тему VOLTFRAME. Реализация: React, React Router и Vite; Bootstrap не используется.

[Открыть VOLTFRAME на GitHub Pages](https://yeayaeyae.github.io/kr5-voltframe/)

## Запуск
Требуется Node.js 20.19+ или 22.12+. Выполните `npm install`, затем `npm run dev`. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Маршруты

- `/` — главная; `/catalog` — каталог; `/catalog/:productId` — товар; `/cart` — корзина; `/order` — форма заявки; неизвестный путь — 404.

## Структура и данные

`src/components/` — общий layout, карточки и состояния загрузки; `src/pages/` — страницы приложения; `src/api/productsApi.js` — API-слой загрузки списка и товара; `src/hooks.js` — загрузка каталога, формат цены и корзина; `public/products.json` — mock-данные 19 товаров; `public/images/` — иллюстрации устройств в WebP и запасные SVG.

Каталог поддерживает поиск, фильтр категорий, сортировку по цене и названию. Состояния загрузки и ошибки с повторным запросом отображаются на странице. Неизвестный ID товара и маршрут обрабатываются отдельно. Форма проверяет имя, телефон, e-mail и согласие; сообщения показываются без `alert()`. Корзина сохраняется в `localStorage`.

## Самостоятельные доработки

Корзина с количеством и общей суммой; локальные responsive-изображения; доступное мобильное меню и reduced-motion; повторная загрузка при ошибках API.

## Три версии дизайна

- `/studio/` — светлая витрина со смартфоном.
- `/orbit/` — тёмная сцена с наушниками.
- `/signal/` — графичная витрина с ноутбуком.

Каждая версия включает каталог, страницы товаров, корзину и заявку. Переключатель версий находится внизу страницы.

На главной 3D-модели поочерёдно вращаются на витрине. Нажатие приближает модель и приостанавливает автопоказ. Есть сцены витрины, коллекции, разборки, характеристик и финала. Переключение доступно кнопками, колёсиком над витриной и с клавиатуры. В карточке товара доступен «Крупный план» с разборкой и осмотром отдельных деталей. При недоступном WebGL отображается изображение модели. При включённой настройке уменьшения движения сцены сменяются сразу.

В каталоге шесть категорий: смартфоны, ноутбуки, наушники, флешки, смарт-часы и пауэрбанки. Выбранный цвет отражается на 3D-модели, а разные цвета одного товара хранятся отдельными позициями в корзине.

## Публикация

GitHub Actions публикует папку `dist/` после коммита в `main`. Команда `npm run build:pages` собирает сайт с базовым путём репозитория и создаёт входные HTML-файлы для прямых ссылок на страницы.
